# 1. Master Blueprint

> **Link to primary source**: [MASTER_BLUEPRINT.md](file:///d:/Projects/Anchor/MASTER_BLUEPRINT.md)

## Summary

The **Master Blueprint** is the constitution of RestaurantOS. It defines:
* **Product Vision**: Offline-first, real-time Restaurant Operating System for single-location operations.
* **Guiding Philosophy**: *RestaurantOS should feel invisible. Employees should focus on serving customers, not operating software.*
* **Litmus Test**: *If an employee has to remember to perform a software action after completing a real-world action, we've designed it wrong.*
* **Core Principles**: Single location first, offline first, real-time sync, touch first, unified auth, role-based experiences, event-driven, automatic where possible, simple over clever, single operational question per screen.
* **Architecture Base**: Built on BusinessOS core platform (Auth, Sync, CQRS, Event Bus, WebSocket Hub, Design System, Audit Log, Notifications).
